# PSZ2 G181: compact-model normalization cross-cluster check

This checks whether the post-hoc normalization hypothesis found for [MACS J1752](../macs1752-model-normalization/README.md) also describes a second cluster, PSZ2 G181.06+48.47. It uses the two T50kpc FITS products and the nominal `compact-model.fits` from the already archived [official survey tarball](../psz2-multiwavelength/manifest.json), whose SHA-256 was verified before extracting named members. All three input hashes are embedded in the script. The model FITS header says Jy/beam; its actual construction and normalization are not verified.

Unlike the MACS products, the two radio images have different dimensions and slightly different beam shapes, and the model uses another grid. Both restored radio images are smoothed to a circular 25-arcsecond Gaussian target and scaled by beam area. The model is treated in turn as (A) a restored Jy/source-beam image, convolved to the target, and (B) unconvolved per-pixel components restored with a unit-peak target Gaussian. All are resampled to the T50SUB WCS grid with bilinear interpolation. Gaussian approximation, header accuracy and resampling affect the result; these operations do not reproduce the full survey imaging pipeline.

Within 180 arcseconds of the chosen cluster-field center, over 25,452 finite pixels, the difference image minus predicted model has an RMS of **2.040 mJy/target beam** under A and **0.056 mJy/target beam** under B. For the 2,617 pixels where B exceeds 0.5 mJy/target beam, the corresponding values are 6.350 and 0.068. The all-pixel comparison is also reported because the thresholded subset is selected using one hypothesis. Values are descriptive residuals across correlated pixels, not noise, significance or a population-wide estimate. The two clusters' products come from the same survey processing family, so this is not an independent pipeline test.

The result is consistent with the per-pixel component hypothesis across two fields, but does not override the header or prove the processing convention, cause of subtraction, source identity, astrophysical bias, merger age or dark-matter properties. Obtain original processing documentation and masks before treating model amplitudes as calibrated.

Run `python research/psz2-model-normalization/analyze.py /path/to/extracted-official-files` with Astropy, NumPy and SciPy; the expected filenames and SHA-256 values are listed in the script. It checks FITS units, positive-definite smoothing kernels, kernel covariance, output scale and finite coverage. The prior official tarball and selected images are in private Azure; this analysis archives the additional extracted inputs. Cite [Botteon et al.](https://arxiv.org/html/2202.11720) and the [LoTSS cluster release](https://lofar-surveys.org/planck_dr2.html) when reusing data. No email was sent.
