# Final-snapshot trajectory fingerprints and merger labels

This is a catalog-internal quality audit, not a merger-tree reconstruction. The hash-pinned TNG-Cluster merger catalog contains 2,083 event rows. For each row with exactly one snapshot-99 entry, use the main component's three positions and three velocities as an exact six-number fingerprint. Reject nonfinite values and positions outside [0, 680000) ckpc/h. No independent test of group membership, low-resolution contamination, or velocity sentinel values is possible from this filter alone.

Of 2,083 rows, 524 have no unique snapshot-99 entry and 29 fail the numerical filter, leaving 1,530 rows. These contain 366 distinct exact fingerprints and 321 distinct recorded `HaloID` values. No fingerprint spans multiple labels, but 39 labels each contain more than one fingerprint; the largest fingerprint group includes 20 event rows. For the 45 comparisons of each label's remaining fingerprints against its lexicographically first fingerprint, none is within both 1 ckpc/h in maximum position component and 0.002 km/s in maximum velocity component. Those thresholds come from the earlier cached-API consistency check and are not uncertainties. Pairing against the first fingerprint is not an all-pairs or tolerance-clustering algorithm.

This shows that grouping solely by the stored label and grouping by exact phase-space vectors are different operations on these selected records. Exact equality can arise from reused inputs; distinct vectors can still belong to the same group or reflect different central subhalos, catalog assignment, or other causes. The check does not determine why a label has multiple fingerprints, prove a defect, establish independent present-day cluster counts, or identify merger descendants. The remaining rows and nonfinite/sentinel cases are excluded; the selected subset is not representative by construction.

Reproduce `python analyze.py /path/to/cluster_mergers.hdf5` with h5py and NumPy. The catalog digest is checked and `grouping.csv` maps each included event to an arbitrary sorted fingerprint group. The prior [cached API check](../event-main-trajectory-check/README.md) independently compared one subhalo's coordinates. For physical interpretation use official snapshot-specific SubLink descendants and FoF group membership rather than labels alone; see [TNG API documentation](https://www.tng-project.org/data/docs/api/) and [TNG-Cluster documentation](https://www.tng-project.org/data/cluster/). No new physics or observational conclusion is made.
