# A bounded reproduction check of an X-ray morphology summary

This exploratory check asks whether a simple ratio of values in the [survey's processed Chandra image](../psz2-multiwavelength/README.md) is numerically consistent with a published X-ray concentration for PSZ2 G181.06+48.47. It does not reconstruct the original event-level analysis, estimate a new physical flux, measure shocks, or validate a merger clock or SIDM model.

[Botteon et al. (2022)](https://www.aanda.org/articles/aa/pdf/2022/04/aa43020-21.pdf), §3.4 and Table A.2, define the concentration as flux within 100 kpc divided by flux within 500 kpc, centered on an X-ray peak, and list **0.141 ± 0.0105** for this cluster. The same paper gives z = 0.240 and a flat H0 = 70 km/s/Mpc, Ωm = 0.3 cosmology. Its method includes event reprocessing, particle-background subtraction, exposure correction, point-source treatment, and an uncertainty calculation using source and background data.

Our local script reads the pinned, already processed and smoothed Chandra image. It takes the brightest finite pixel within 500 kpc of the published Ahn et al. mass-peak barycenter as a repeatable search rule; that is **our selection rule**, and we have not verified it matches the authors' point-source mask or exact center. It sums the image values in pixel-center circular apertures of 100 and 500 kpc, with no further correction. At z = 0.240 the result is **0.1397**, compared with the table's 0.141. Agreement of these central numbers is a useful numerical sanity check, not proof that we have reproduced the authors' pipeline or uncertainty. We have neither the source/background counts nor their uncertainty propagation. The image lacks a BUNIT keyword, and its FITS history shows particle-background subtraction, division by an exposure map, smoothing, and multiplication by 1,000,000. The multiplicative factor cancels in this ratio; an additive background or other processing difference would not. An independent calculation using actual sky-coordinate separations, rather than the script's pixel-radius approximation, returns the same ratio to displayed precision.

For a deterministic sensitivity illustration, shifting the chosen center by 5 arcsec in four image-axis directions gives ratios between **0.1340 and 0.1441**; these offsets are not samples from an astrometric posterior or confidence interval. Keeping the same chosen pixel but using z = 0.234 changes the ratio to 0.1419. These choices affect the number, but neither comparison isolates a physical effect. The image WCS date metadata warnings and unknown physical brightness units are recorded in `summary.json`; the coordinate round-trip is not an independent registration check.

The [figure](concentration-apertures.png) shows the proposed apertures on the processed image. A reproducible paper-level measurement needs the original event list, exposure/background and point-source masks, documented exact centering and aperture definitions, covariance and counts-based uncertainty calculation. The original 0.141 value is a prior published result; no novel finding or independently reproduced observation is claimed.

Reproduce `python analyze.py /path/to/PSZ2G181.06+48.47CHANDRA.fits` with NumPy, Astropy and matplotlib. The [earlier manifest](../psz2-multiwavelength/manifest.json) pins the image digest; the data were previously saved to private Azure. If necessary use a fresh `MPLCONFIGDIR` for the font cache. Cite Botteon et al., Chandra and the source archive when reusing the image. No email was sent.
