# Pericenter scaling hypotheses

The official [TNG-Cluster download listing](https://www.tng-project.org/data/downloads/TNG-Cluster/) gives h=0.6774; the supplementary catalog header itself does not provide a cosmology. The [field documentation](https://www.tng-project.org/data/cluster/) describes `Mhistory_orbit` and `d_peri` as ckpc/h. This analysis tests a numerical pattern, not the true units or the authors' processing. It uses the prior 1,977 selected event rows, three adjacent valid snapshots, nearest-image coordinate differences and the saved snapshot redshifts.

For each event and each multiplier, calculate the absolute difference between the catalog `d_peri` number and each of the three scaled coordinate separations; retain the smallest. Candidate multipliers are 1, 1/h, a, and a/h with the official h, plus a/h with h=0.67 and h=0.69 as numerical sensitivity checks. Median absolute difference divided by positive `d_peri` is 0.117 for 1, 0.376 for 1/h, 0.180 for a, and approximately 2.7e-16 for a/h with h=0.6774. Under an absolute numeric difference of 0.01, the counts are 0, 0, 0 and 1,428 respectively. At a relative tolerance of 0.001 the a/h count is 1,454. The two altered h values yield no absolute matches under 0.01 on this sample. The best-of-three choice, diagnostics and h perturbations are exploratory and can produce incidental agreement; thresholds are not error bars.

This strongly identifies the *numerical scaling pattern* in these selected rows but does not prove that the published `d_peri` is in proper units, which snapshot/algorithm was used, whether release versions differ, or whether documentation is erroneous. `d_peri` may not be a direct snapshot distance for the remaining events. Do not apply a field conversion or compare prior fitted comoving distances to catalog values as a validated residual until source construction is independently established. Repeated merger events are not independent clusters.

Reproduce `python analyze.py /path/to/cluster_mergers.hdf5` with NumPy/h5py and the adjacent prior selection and redshift tables. It checks the catalog SHA-256, records the selected-row input digest, and writes row-level comparisons. An independent standard-library count recovered the earlier 1,428 count. [Lee et al. (2024)](https://arxiv.org/html/2311.06340) describes a five-point fit; reconciling that method with the current release requires exact source construction or author clarification.
