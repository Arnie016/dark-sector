# Aperture-edge audit

The earlier scripts measured the fraction of *in-array* circle pixels with common valid coverage, but did not explicitly reject a circle extending beyond the reference image. That could report 100% coverage for a clipped aperture. We checked the actual catalog positions and largest **600 kpc** apertures in the hash-pinned T50SUB reference images. All four fit within the pixel-center bounds: the closest is PSZ2 G181's southern aperture, whose minimum margin is **34.55 pixels (69.10 arcseconds)**. Smaller concentric apertures also fit. The previous physical-beam paired-image results therefore are not invalidated by a reference-image edge cut in these cases. Their common finite-pixel checks still apply to the convolved and resampled images.

Eight related analyses now reject apertures that extend beyond the reference array before computing their in-array coverage fractions. We reran all eight on the archived data; each completed and the tracked numeric outputs remained unchanged. The audit independently inspects each actual guard condition and checks that an interior synthetic circle is accepted and a left-edge-clipped circle is rejected. This is a geometry and regression check, not verification of source masks, physical center definitions, noise covariance or merger-clock inference. The conservative guard measures to the outermost pixel centers rather than pixel edges.

## Reproduce

Run `python research/aperture-edge-audit/audit.py /path/to/macs-maps /path/to/psz2-maps /path/to/rrsamp.tsv` with NumPy and Astropy. It checks source hashes, catalog identity, WCS pixel scales and all four positions, and evaluates the guard expressions from the eight current scripts against synthetic inside and clipped cases. It writes `summary.json`. The target checks use the SUB reference grids; the pair analyses separately test common finite coverage after convolution and regridding. Cite [Botteon et al.](https://arxiv.org/abs/2202.11720) and the [LoTSS cluster release](https://lofar-surveys.org/planck_dr2.html).
