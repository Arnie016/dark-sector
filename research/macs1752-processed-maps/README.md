# MACS J1752: official processed radio maps

The [LoTSS Planck-cluster page](https://lofar-surveys.org/clusters/PSZ2G071.21%2B28.86.html) links a 71,739,765-byte FITS tarball for MACS J1752 (PSZ2 G071.21+28.86). We retrieved it under a 75 MB cap, recorded its SHA-256, inspected the member listing without extracting untrusted paths, and selected `T50kpcSUB.fits` (10,428,480 bytes) and `T100kpcSUB.fits` (1,520,640 bytes). The original archive, selected files and catalog are retained privately in Azure; only the derived plot, code and manifest are versioned in GitHub. Names identify the provider's image products; precise processing and masks must be verified with the source documentation before quantitative use.

Both FITS images have JY/BEAM units and celestial WCS, and both published Botteon relic coordinates fall within finite image coverage. Their respective header beam FWHM values are 14.73 × 10.64 and 30.47 × 27.78 arcseconds. The panels use the same display stretch, but brightness in Jy/beam is not directly comparable between different beams; the fields of view differ as well. Cyan crosses show published catalog positions, not positions measured by our script. Astropy emits a FITSFixedWarning because it derives MJD-OBS from the provided DATE-OBS; the original headers remain unchanged. The images share observations and processing, so they are not independent datasets.

This is a real data product useful for testing position definitions, but it does not by itself provide the authors' masks, noise covariance, exact position extraction, a calibrated shock front, or a merger age. No new detection, flux, separation, statistical uncertainty or physical constraint is claimed. A defensible future analysis needs beam-aware matched resolution, same-region masks and noise estimation, source-subtraction diagnostics, and original measurement definitions.

Run `python research/macs1752-processed-maps/analyze.py /path/to/selected-maps /path/to/rrsamp.tsv`; the selected directory must contain the names in `manifest.json`. Requires Astropy, NumPy and matplotlib; the script checks source hashes, brightness units, WCS and finite coverage. Cite [Botteon et al.](https://arxiv.org/html/2202.11720), the [LoTSS DR2 release](https://lofar-surveys.org/dr2_release.html), and follow survey acknowledgements and reuse terms. No email was sent.
