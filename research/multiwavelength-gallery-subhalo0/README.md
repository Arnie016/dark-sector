# Gas and X-ray gallery views for TNG-Cluster subhalo 0

The [official gas-column-density gallery](https://www.tng-project.org/cluster/gallery/nelson23/) and [X-ray-emission gallery](https://www.tng-project.org/cluster/gallery/nelson23xray/) each link their first three x/y/z views to TNG-Cluster snapshot 99 subhalo 0, the same gallery API target as our earlier [radio views](../relic-gallery-subhalo0/README.md). The source describes 352 target halos at z=0 and three viewing directions. The retrieved X-ray images label the band 0.5–5 keV. The gas images label column density. Both are rendered simulation products, not observations.

On visual inspection, the x-axis gas and X-ray views show a bright central complex and off-center emission at a similar apparent location. The renderings use different physical quantities and color scales; overlays, nonlinear color mapping, projection depth, clipping and other rendering details can affect appearance. We have not verified pixel-level co-registration, calibrated map values, independent shock positions, or lensing observables. The agreement of gallery links and labels identifies the **present-day gallery target**, not a unique event history: our event-5 linkage is limited to the previously cached snapshot-99 subhalo position and velocity check, not a verified merger tree. Do not associate a specific visible feature with that event or infer SIDM.

`manifest.json` records the official URLs, axis, hash, byte size and image dimensions. `python fetch.py` retrieves six bounded public PNGs and verifies length and SHA-256 into a git-ignored `images/` directory; the repository does not redistribute the image files. The files total 3,009,037 bytes and were copied to a private Azure archive together with the manifest. Honor the source's citation and reuse conditions; these are not a replacement for numerical data.

For a scientific measurement, obtain calibrated numerical gas, shock and projected total-mass maps for the same simulation, snapshot, axes, center, field of view and depth, plus noise/selection models and independent branch IDs. The [TNG-Cluster documentation](https://www.tng-project.org/data/cluster/) describes projection quantities and their much larger file sizes, and the [radio-relic study](https://arxiv.org/html/2510.21632) provides a benchmark for radio/relic identification. No calibrated join, shock extraction, observational comparison, or paper-level result has yet been performed.
