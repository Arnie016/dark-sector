# Abell 1925: catalog sources near the two difference peaks

We queried the [LoTSS DR2 raw radio catalog](https://cdsarc.cds.unistra.fr/viz-bin/cat/J/A+A/659/A1) within 70 arcseconds of each post-hoc difference maximum in the [paired-map exclusion experiment](../g099-feature-influence/README.md). The selected FITS WCS positions are FK5 J2000 and are transformed to ICRS before comparison; the catalog J2000 numeric coordinates are treated as ICRS, with absolute frame and astrometric uncertainties not independently verified. The input FITS and original query responses are hash-checked.

The northern query returns four catalog rows. The nearest is `ILTJ142754.33+565926.2`, **5.13 arcseconds** from the selected peak; its cataloged fitted major/minor FWHM are 60.29 × 20.75 arcseconds, including the catalog image's 6-arcsecond beam, and its source-structure code is `M`. The southern query returns two rows. The nearest is `ILTJ142910.26+564216.3`, **1.90 arcseconds** from the southern peak; its fitted FWHM is 6.91 × 6.47 arcseconds and its code is `S`. All returned candidates and distances are in `summary.json`.

These are **positional associations**, not independent detections: the catalog and maps derive from related LoTSS observations, the 135 kpc analysis beam is approximately 70 arcseconds, and the image peaks were selected after inspection. The catalog size estimates and image-difference peak are not equivalent centroids. The matches do not prove which source caused either difference, whether either belongs to the cluster, whether the survey's subtraction is erroneous, or whether a merger-clock estimate is biased. We do not calculate a chance-association probability or redshift.

## Reproduce

The saved VizieR ASU queries use source `J/A+A/659/A1/catalog`, radius 70 arcseconds and a maximum of 1,000 rows; their exact requests and unmodified responses are archived privately in Azure. Run `python research/g099-radio-source-crossmatch/analyze.py /path/g099-T50kpcSUB.fits /path/N.tsv /path/S.tsv` with Astropy. The program checks input and response SHA-256 hashes, confirms the FITS WCS frame and saved peak pixel coordinates, and recomputes separations. It assumes catalog positions are ICRS, records all returned candidates and writes `summary.json`. Cite [Shimwell et al.](https://arxiv.org/abs/2202.11733), [Botteon et al.](https://arxiv.org/abs/2202.11720) and VizieR DOI 10.26093/cds/vizier.36590001.
