# PSZ2 G181: rotated exclusion-mask sensitivity

This follows the [post-hoc boundary exclusion](../psz2-boundary-ablation/README.md). On the same 135 kpc-beam maps, 600 kpc relic apertures, 0.2 mJy/beam threshold and brightest-10% center rule, we apply a 40-arcsecond circle to both maps at 36 positions. The first is centered on the previously selected positive difference peak; the others rotate that location in 10-degree increments around the southern catalog position in the image-pixel plane. All positions have the same nominal radial distance; masks overlap and the locations have different sky brightness. The test was designed after seeing the first result.

With no exclusion, the T50 minus T50SUB pair difference is **−270.58 kpc**. Excluding the selected peak gives **+6.50 kpc**; the 35 other locations give values from **−282.60 to −66.77 kpc**. None of those other sampled masks brings this value as close to zero as the selected mask. This is a descriptive sweep of this estimator, **not a p-value or an independent detection**: the peak was selected because the images differed there, adjacent masks overlap, and both maps share observations.

The selected mask removes 605 threshold-eligible southern pixels in T50 and 239 in T50SUB. If we apply the post-hoc condition that both counts be within 25% of these values, only the 10-degree rotation qualifies; it gives −66.77 kpc. Its mask overlaps the selected circle by approximately 56% of the full circular area under a flat-pixel approximation, so it is not an independent matched control. Pixel counts do not match the excluded flux distributions, beams or spatial correlations. The sweep strengthens the local influence diagnosis but cannot establish a physical source, statistical significance, uncertainty, population bias, or change to a published merger clock.

## Reproduce

Run `python research/psz2-rotated-mask-sweep/analyze.py /path/to/psz2-maps /path/to/rrsamp.tsv`, using the previously archived files and NumPy, SciPy, Astropy and Matplotlib. The script verifies input hashes, beam-kernel covariance, common coverage, and agreement of the no-exclusion and selected-peak results with the prior analysis. It writes 148 coordinate rows, `summary.json` and `sweep.png`. An independent coordinate calculation verified all 37 pair differences. The 25% count criterion is an explicitly post-hoc diagnostic and is not a preregistered selection. Cite [Botteon et al.](https://arxiv.org/abs/2202.11720), [Shimwell et al.](https://arxiv.org/abs/2202.11733) and the [LoTSS release](https://lofar-surveys.org/planck_dr2.html).
