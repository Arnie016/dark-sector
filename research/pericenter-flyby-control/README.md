# Five-point pericenter fit on non-quadratic flybys

The five-point prototype was motivated by [Lee et al. (2024), section 2.2](https://arxiv.org/html/2311.06340), but its window and conventions are not verified as the paper's exact implementation. This control tests the prototype's fit shape, not the catalog's error.

Define a straight-line constant-speed proper-coordinate flyby with separation `r(t) = sqrt(b^2 + [v (t-t0)]^2)`, where `b` is the known minimum and `v` is transverse speed. Convert 1 kpc/Gyr = 0.9777922217 km/s. It is non-quadratic and excludes gravity, cosmological expansion, gas, noise, and halo-center switching. The exact minimum is b at t0. Sample at the actual cosmic-age spacings for TNG snapshots 68–72 using the prior redshift table and the flat matter-plus-Lambda approximation. Place t0 at 101 evenly spaced phases between snapshots 69 and 70; these phases form a deterministic sensitivity grid, not a probability distribution. Fit the same unweighted five-point scalar quadratic as the prototype, centered on snapshot 70, and apply the same positive-curvature, in-window and nonnegative-vertex checks.

All 101 fits per case pass. For speed 3,000 km/s, median fitted-minus-true distance across the phase grid is approximately +215, +178, +91, and +16 kpc for b = 50, 100, 300, and 1,000 kpc respectively. Median absolute time errors range from about 3 to 10 Myr in these cases. At 1,500 km/s the corresponding distance biases are approximately +89, +63, +20, and +1.6 kpc. In this idealized family, a close, rapid passage is sharply curved and the quadratic over these five spaced samples overestimates the true minimum. This is not a bound, correction, or validation for real mergers: actual trajectories, phase distribution, branch selection, peculiar/comoving conventions and switching corrections differ.

`python analyze.py` reproduces all 808 deterministic combinations, figure, CSV and summary with NumPy and Matplotlib, using the adjacent saved TNG snapshot redshifts whose hash is recorded. A separate dense-grid calculation verified the analytic minimum in the b=100 kpc, v=3,000 km/s case. For a physical study, extend to dynamically integrated two-body orbits and matched tracers, then reproduce a source-verified event. The simulation is not a detection or SIDM constraint.
