# Cluster merger to present-day properties: identifier audit

The corrected merger HDF5 and the independently downloaded TNG-Cluster properties HDF5 are pinned by SHA-256 in `analyze.py`. The [official documentation](https://www.tng-project.org/data/cluster/) distinguishes the merger event `HaloID`, the parent dark-matter-only original halo IDs, and the virtual-box group IDs; it does not establish an equality join from the merger-event field to either z=0 properties key. The properties table contains 352 unique `origID` and 352 unique `haloID` entries.

The merger catalog has 2,083 rows and 346 distinct recorded `HaloID` values. Numeric equality against the 352 properties `origID` values matches 1,311 event rows across 165 distinct values; equality against the z=0 virtual `haloID` values matches 11 rows across one distinct value. Neither overlap proves a valid physical match. The unmatched values and accidental equal numbers make a naive direct join unsuitable without a documented ID mapping or tree-based validation.

As a limited diagnostic, among 31 events whose `Snap_coll` is 99 and collision M200 is positive, 12 have a numeric `origID` match. Under that unverified join the median absolute log10 mass difference from the properties catalog is 0.0725 dex and the 90th percentile is 0.278 dex; none agrees within 0.001 dex. This is not proof of a wrong join or a field error: M_Crit200_coll is measured around first pericenter whereas the properties table is at z=0, and definitions, interpolation, units or halo assignment may differ. The diagnostic deliberately does not use these provisional matches in a scientific sample.

Reproduce using `python analyze.py /path/cluster_mergers.hdf5 /path/TNG-Cluster_Catalog.hdf5` with h5py and NumPy. The decisive next check is a documented mapping or a SubLink/official API descendant trace with snapshot-specific group identifiers and independently checked masses for several cases. TNG's zoom regions and low-resolution particles must be respected. The [Lee et al. merger and radio-relic study](https://doi.org/10.1051/0004-6361/202348194) is a relevant scientific benchmark, but we cannot yet map its Halo 3 example by numeric label alone. No causal or SIDM claim follows.
