# Centroid-shift check on the processed Chandra image

This is a numerical check of a published X-ray morphology value using the source team's processed image. It is not an independent observation, full reproduction of the event-level pipeline, new merger-age measurement, or SIDM constraint.

[Botteon et al. (2022), §3.4 and Table A.2](https://openaccess.inaf.it/bitstream/20.500.12386/36188/1/2202.11720v2-compressed.pdf), define the dimensionless centroid shift `w` as the sample standard deviation of peak-to-centroid distances across apertures, divided by 500 kpc. For Chandra they use annuli with 5 arcsec widths inside the 500 kpc outer aperture, and tabulate **w = 0.0695 ± 0.00304** for PSZ2 G181.06+48.47. Their concentration for the same row is **0.141 ± 0.0105**. An earlier project note mistakenly attributed 0.00639, the concentration error from a neighboring row, to this cluster; that note and its generated summary have been corrected. Older immutable Azure copies are historical and superseded by the corrected copy archived alongside this analysis.

The local script reads the same SHA-256-pinned, processed Chandra image as the [concentration check](../psz2-xray-concentration/README.md). It selects the brightest pixel within 500 kpc of the mass-peak barycenter from Ahn et al. (2025); this deterministic rule is ours and is not verified to reproduce the authors' source mask and center. It calculates intensity-weighted centroids in 26 circular apertures of 5, 10, ..., 130 arcsec, where 130 arcsec is about 493 kpc at the paper's z = 0.240 and cosmology. The sample standard deviation of the 26 peak-to-centroid distances divided by 500 kpc is **0.06933**, versus the published 0.0695. A second calculation from the exported per-aperture distances, using Python's `statistics.stdev`, independently verifies the final arithmetic.

This agreement provides a useful consistency check on the selected processed image and a plausible implementation of the statistic. It does **not** verify the original authors' exact apertures, center, source exclusion, masking, exposure correction, Poisson uncertainties or science interpretation. The calculation uses image pixel values as weights including negative values, without new background or exposure treatment. The file lacks BUNIT and has inconsistent timestamp metadata; WCS transformation and pixel scale are used only for spatial geometry. The residual to the rounded table value is not a statistical significance test. `aperture-centroids.csv` contains the per-aperture values and `centroid-apertures.png` shows their variation. No error bar or physical conclusion is estimated here.

Reproduce `python analyze.py /path/to/PSZ2G181.06+48.47CHANDRA.fits` using Astropy, NumPy and matplotlib. The script checks the image hash using the adjacent prior manifest. The corrected concentration check, this analysis and the prior data are versioned in GitHub and private Azure. Paper-level validation needs source counts, background and exposure products, author mask and centering details, plus the reported Monte Carlo uncertainty procedure. Cite the survey and Chandra when reusing imagery. No email was sent.
