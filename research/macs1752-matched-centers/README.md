# MACS J1752: matched-map center sensitivity

This is a descriptive paired experiment on two processed maps of the **same observations**, not an independent observation, a measurement error, a confidence interval, a detection or a merger-age calculation. The [beam-matching pipeline](../macs1752-beam-match/README.md) smooths the T50kpcSUB map to the T100kpcSUB restoring beam and target WCS, converts beam units, and verifies its Gaussian kernel. Differences in imaging, residual compact sources, noise and transfer function remain; pixels and map products are correlated.

On both maps, define the same circular regions of radius 60, 90 and 120 arcseconds around the previously published north and south catalog coordinates. Within common finite coverage, select pixels above 0.1, 0.2 or 0.3 mJy/target beam and compute an intensity-weighted center of the brightest 10% of eligible pixels. The regions and thresholds are deliberately illustrative and catalog-seeded; they are not the source authors' masks, validated noise cuts, or an independent position measurement. A 30.47 × 27.78 arcsecond target beam does not provide a formal uncertainty for these centers.

Across nine paired configurations, the north centers differ by 1.67–2.67 arcseconds between the two maps; the south centers differ by 1.65–2.42 arcseconds. The signed difference in north–south pair separations (matched T50 minus T100) ranges from −0.33 to +0.25 arcseconds. The small numbers summarize this one set of bright-pixel rules and cannot establish precision or bias, rule out other processing differences, or reproduce a simulation clock. Identical regions do not guarantee identical selected pixels: eligible pixels and the brightest 10% are chosen separately in each image. A paired position analysis with original masks, measurement definitions, beam/noise covariance and a source-verified simulation baseline remains needed.

Run `python research/macs1752-matched-centers/analyze.py /path/to/selected-maps` with Astropy, NumPy, SciPy and matplotlib. It calls the adjacent beam-matching script, which checks the source hashes and regenerates its own summary and plot, then writes 36 rows and this analysis's summary and plot. A separate count verified each image/relic/configuration occurs once and the top-10% counts.
