# Five-point window sensitivity in merger histories

[Lee et al. (2024)](https://arxiv.org/html/2311.06340) describes a quadratic fit to five separation samples closest to first pericenter. The exact window selection and switching corrections are not established here. Using the hash-verified corrected TNG-Cluster merger catalog, this exploratory check compares two provisional comoving-separation fits per event: snapshots `Snap_coll-3 ... Snap_coll+1` and `Snap_coll-2 ... Snap_coll+2`. Both use nearest-image periodic coordinates and the same flat matter-plus-Lambda time approximation. Only events with all six unique valid snapshots and two convex, nonnegative, in-window quadratic vertices are retained. The comparison uses the same event rows in both windows.

Of 2,083 catalog rows, 1,818 pass both fits; 63 are outside the usable range, 49 lack a unique history sample, 38 fail position validity, and 115 have at least one invalid fit. Among accepted events, shifting the window by one snapshot changes the fitted time by a median 0.0227 Gyr and 90th percentile 0.0521 Gyr; the absolute fitted comoving separation changes by a median 15.8 ckpc/h and 90th percentile 47.3 ckpc/h. These are changes between particular implementations, not physical uncertainties, a catalog error rate, or a comparison to the actual paper pipeline. Filters and repeated halos prevent population-wide inference. Position, time, branch and `d_peri` conventions remain unverified.

An independent check matched the right-hand fit against the earlier saved comoving prototype for all 1,817 shared events. One additional event is accepted here because the earlier code also required its *proper*-distance fit to pass; the paired sample therefore differs from the earlier sample. The prior prototype included synthetic uneven-grid quadratic recovery tests. Run `python analyze.py /path/to/cluster_mergers.hdf5` with h5py/NumPy and the adjacent snapshot-redshift file. The script checks the catalog and records the redshift digest; `paired.csv` contains event-level fits.

Before a manuscript claim, recover the authors' exact window, units and switching treatment, independently trace merger identities, and compare a source-verified event. This is simulated catalog research, not an observed or SIDM result.
