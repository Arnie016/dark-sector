# MACS J1752: catalog near the image-difference peak

A 20-arcsecond cone query of the [LoTSS DR2 raw radio catalog](https://cdsarc.cds.unistra.fr/viz-bin/cat/J/A%2BA/659/A1) around the [T50 − T50SUB difference peak](../macs1752-difference-localization/README.md) returned one row, **ILTJ175159.28+443849.6**, 5.29 arcseconds from the peak using the rounded catalog coordinates. A separate 5-arcsecond query of the [LoTSS value-added catalog](https://cdsarc.cds.unistra.fr/viz-bin/cat/J/A%2BA/678/A151) at that radio-catalog location returned the same source identifier; the two tabulated radio positions agree to 0.021 arcseconds. The raw catalog assigns morphology code M, meaning an extended source fit with multiple Gaussians; its fitted major/minor FWHM are 20.69 × 14.41 arcseconds, including the catalog beam.

This is a **positional association**, not proof that this catalog entry causes the observed image difference. The radio maps and the catalog derive from related LoTSS observations, so this is not independent detection evidence. The difference peak is a selected image pixel, not a fitted centroid with a measured uncertainty; the nearby catalog source is extended and its coordinates refer to a different catalog extraction and beam. Differences between J2000 catalog and image-coordinate conventions, resolution and processing require care. We do not assert an optical identification, redshift type, cluster membership, source physics, compact-source subtraction mechanism, or merger-clock bias from this match. The value-added query includes a `zbest` field, but its provenance and reliability for this object were not established, so no membership inference is made.

Both exact VizieR requests, catalog links, retrieval date and response SHA-256 values are in `manifest.json`. Reproduce with `python research/macs1752-patch-catalog/analyze.py /path/raw-query.tsv /path/value-added-query.tsv` using Astropy. The script checks both response hashes, expected single-row counts, matching radio identifiers and the independently recomputed sky separation. The raw responses are stored in private Azure; the earlier processed radio maps and analysis are separately archived. Respect the [VizieR catalog license guidance](https://cds.unistra.fr/vizier-org/licences_vizier.html) and cite the appropriate survey and value-added releases when reusing data. No email was sent.
