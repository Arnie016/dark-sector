# Catalog-screened variation in matched radio maps

This is a follow-up to the [geometry-only patch diagnostic](../two-cluster-background-patches/README.md). We query the [LoTSS DR2 radio catalog](https://cdsarc.cds.unistra.fr/viz-bin/cat/J/A+A/659/A1) within 25 arcminutes of each image center. The saved responses contain 314 MACS and 549 PSZ2 catalog rows, below the 10,000-row query limit. Candidate patch corners plus two arcminutes of padding fit inside each query circle; the script checks the recorded query centers and radii. Catalog J2000 coordinates are treated as ICRS, as in earlier catalog comparisons.

On the same 135 kpc-beam, common-grid maps and 4 × 4 geometry-defined patch grid, we mask each catalog position by a circle with radius equal to the larger of 1.5 times the target-beam FWHM or the catalog's fitted major FWHM, capped at 120 arcseconds. The cap affects one PSZ2 source and none in MACS. This deliberately simple rule does not use source shape or sidelobe models and can miss flux from extended or uncataloged objects. We retain patches with at least 99% common finite coverage and at least 50% of their pixels after catalog screening; the same remaining sky pixels are used in both maps. Twelve MACS and seven PSZ2 patches pass.

The median across accepted patches of `1.4826 × MAD` is **0.230 / 0.227 mJy/target beam** for MACS T50 / T50SUB and **0.169 / 0.158 mJy/target beam** for PSZ2. Full patch ranges are 0.142–0.308 / 0.148–0.314 for MACS and 0.087–0.260 / 0.079–0.223 for PSZ2. These medians differ from the earlier geometry-only values, but both the patch membership and pixel masks changed, so the difference is not an isolated estimate of catalog-source contamination.

These are **screened local-variation diagnostics**, not validated source-free RMS values, confidence intervals or detection thresholds. Catalog incompleteness, diffuse emission, source-mask caps, astrometric assumptions, reimaging artifacts, backgrounds and spatially correlated pixels remain. Patches are only about 1.9 beam widths across; their pixels are not independent noise samples. No published relic position or merger-clock inference is reproduced or corrected.

## Reproduce

Run `python research/catalog-screened-background/analyze.py /path/macs-maps /path/psz2-maps /path/rrsamp.tsv /path/macs-catalog.tsv /path/psz2-catalog.tsv` with NumPy, SciPy, Astropy and Matplotlib. The two VizieR ASU TSV queries use `J/A+A/659/A1/catalog`, 25-arcminute cones and a 10,000-row limit; exact requests and SHA-256 hashes are preserved with the raw responses in private Azure. The script checks image/catalog identities, query geometry, map hashes, target-beam kernels and coverage. The CSV includes rejected patches and the number of remaining pixels. A separate read verified patch counts and medians. Cite [Shimwell et al.](https://arxiv.org/abs/2202.11733), [Botteon et al.](https://arxiv.org/abs/2202.11720) and VizieR DOI 10.26093/cds/vizier.36590001.
