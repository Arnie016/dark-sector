# MACS J1752: Gaussian beam-matching diagnostic

The two [official processed radio maps](../macs1752-processed-maps/README.md) have different fitted elliptical restoring beams, pixel grids and processing. This diagnostic smooths the T50kpcSUB image to the T100kpcSUB header beam and samples it on the latter image's celestial grid. The Gaussian covariance uses FITS beam major/minor FWHM and position angle; the target-minus-input covariance is positive definite. A normalized kernel is formed on the source pixel grid, and Jy/source-beam is converted to Jy/target-beam by the ratio of Gaussian beam areas (5.402). Bilinear sampling is used after smoothing, with finite-coverage checks. The program verifies the input hashes, positive kernel covariance, discrete kernel covariance against its target, normalized kernel, and target pixel scale.

Within two catalog-centered 120-arcsecond circles, 10,057 finite target-grid pixels have a median signed difference of 0.034 mJy/target beam, median absolute difference of 0.169, and RMS difference of 0.926. These are descriptive pixel statistics, not independent observations, noise estimates, significance levels, flux differences or centroid uncertainties. Pixels and the two source maps are correlated, and high values affect RMS. The plot omits values outside ±3 mJy/target beam for readability; summary statistics use all included pixels. The map products can differ for reasons beyond restoring beam, including their imaging, weighting, source subtraction and noise. Gaussian restoration is an approximation, and local WCS plus bilinear resampling introduces interpolation effects. No point-by-point equality is expected.

This is a prerequisite check for, not a substitute for, a matched relic-position analysis. It does not reproduce the original masks or source extraction; before inference obtain those masks, calibration and a noise/beam covariance model and compare identical physical definitions. No merger age or dark-matter constraint follows.

Reproduce with `python research/macs1752-beam-match/analyze.py /path/to/selected-maps` using NumPy, SciPy, Astropy and matplotlib. Source hashes and the file provenance are in the adjacent [manifest](../macs1752-processed-maps/manifest.json). No data are downloaded by the script and no email was sent. Cite the [LoTSS cluster release](https://lofar-surveys.org/planck_dr2.html) and [Botteon et al.](https://arxiv.org/html/2202.11720) when reusing the data.
