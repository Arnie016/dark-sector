# PSZ2 G181 lensing mass-correlation sensitivity

[Ahn et al., Tables 1 and 2](https://arxiv.org/html/2501.09067) report the northern and southern M200c masses as 0.88 (+0.35, -0.30) and 2.71 (+0.51, -0.48), in units of 10^14 solar masses, with Pearson correlation -0.574 for the fiducial mass–concentration relation. [Jee et al., Table 2](https://arxiv.org/html/2605.00093v2) also use these cluster masses in a wider radio-relic cluster analysis. This check does not establish how their analysis handles the joint posterior.

The ratio of the central values is 0.325. For an illustrative first-order calculation, replace each asymmetric error by its average (0.325 and 0.495), and use those as proxies for standard deviations. The resulting approximate ratio uncertainty is 0.161 with the published correlation and 0.134 with zero correlation, an increase of 20.7%. This is a sensitivity exercise, not a posterior, confidence interval, new dark-matter constraint, or reproduction of either paper's inference. Quoted error bars are not guaranteed to equal standard deviations, the linear approximation is imperfect for these substantial asymmetric errors, and the published correlation alone does not recover the full joint distribution. Model and measurement systematics are also omitted.

The paper defines the total system mass through a combined three-dimensional density profile; it is not simply the sum of these component M200c values. A usable quantitative comparison needs the joint mass posterior or source shear catalog, model assumptions and systematics; a registered, calibrated convergence map would also be needed for a map-level comparison. A search of the paper and public indexing did not verify a downloadable convergence map, which is not proof that one does not exist.

Run `MPLCONFIGDIR=/tmp/psz2-plot-config python3 research/psz2-lensing-covariance/analyze.py` from the repository root with NumPy and Matplotlib installed. The script writes the summary and plot and checks its analytic gradient against finite differences and an independent scalar expression. Input values and sources are in `input.json`.
