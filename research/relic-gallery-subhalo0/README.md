# TNG-Cluster radio-gallery views for snapshot 99 subhalo 0

The [official Lee+ radio-synchrotron gallery](https://www.tng-project.org/cluster/gallery/lee23/) displays three z=0 views for each TNG-Cluster target and labels this quantity as radio synchrotron emission at 1.4 GHz. The [source paper](https://arxiv.org/html/2311.06340) describes its radio post-processing and points readers to the gallery. The three images in `manifest.json` are the gallery's first x/y/z views, each directly linked by the gallery to [TNG-Cluster snapshot 99 subhalo 0](https://www.tng-project.org/api/TNG-Cluster/snapshots/099/subhalos/00000000/). They are 800x873 rendered PNGs, totaling 787,008 bytes.

Our earlier `event-main-trajectory-check` matched nine merger-event main-history positions and velocities to a minimized previously retrieved subhalo-0 API record at snapshot 99. The gallery's link therefore supports a concrete connection to that *present-day subhalo reference*. The matching coordinates do not prove an independently verified merger-tree branch or that any particular feature in the image came from event row 5. Row 5's recorded first-pericenter snapshot is 70; these are snapshot-99 images, not maps at that passage. Labels, possible selection changes and pericenter definitions still require independent verification.

The three views visibly have different projected structures. This qualitative observation illustrates projection dependence; the images are rendered illustrations with circles, text, colormaps and different overlay area, not calibrated 2D arrays with an independently verified mask, physical coordinate transform, uncertainty, lensing map or shock catalogue. Do not measure shock positions, estimate radio fluxes, claim a relic classification, or infer SIDM from rendered pixels. Follow the collaboration's attribution and reuse terms before republishing imagery. This repository records source URLs and hashes but does not embed the external images.

Run `python fetch.py` for a bounded download of the same three official images into the git-ignored `images/` directory. Each response is limited to 5 MB and checked against the recorded byte length and SHA-256; the script fails closed if upstream files change. The manifest and three images were also copied to the private Azure archive. For a meaningful physics comparison, obtain source-provided calibrated projections, axes/scale metadata, the matching redshift and a verified descendant/tree identity; obtain radio shock-finder output and lensing-like mass maps and validate selection against the [double-relic analysis](https://arxiv.org/html/2510.21632). No observational or new-physics claim is made.
