# LoTSS cluster-image processing and compact-model provenance

[Botteon et al. (2022), §3.3](https://arxiv.org/html/2202.11720#S3.SS3) describe the survey's general imaging method: WSClean version 2.8, Briggs weighting and several Gaussian uv tapers; they create a model of discrete sources using a uv cut, subtract clean components from the visibility data, and re-image with the same taper settings. The paper says the resulting images are made available through the project website. It also notes that source subtraction can remove some relic emission in at least one particular system; this is not evidence that the same occurred in either of our fields.

[WSClean's version 2.7 release notes](https://wsclean.readthedocs.io/en/latest/changelogs/v2.7.html) report storage of model files in Jy/pixel. This is consistent with the [two-field numerical tests](../psz2-model-normalization/README.md) that better reproduce the T50 minus T50SUB image differences when treating the nominal `compact-model.fits` as unconvolved per-pixel components. It is supporting provenance, not proof that each delivered `compact-model.fits` is an unmodified WSClean model or that its exact version and normalization can be deduced from its name. In the two files we inspected, the FITS header states `BUNIT=JY/BEAM`, so the mismatch between header and working hypothesis remains unresolved. Do not silently rewrite the header or apply the inferred convention to other files.

The visibility-domain subtraction described in the paper also means that a difference of re-imaged FITS products need not equal a simple image-domain model convolution exactly: weighting, deconvolution, image restoration, masking and calibration may differ. The T50 versus T50SUB comparison is a useful diagnostic of product sensitivity but cannot isolate a physical relic shift, prove a specific source caused a change, estimate uncertainty, or establish a merger-clock bias. The original products, exact imaging configuration and source masks are still needed for a calibrated inference.

Source comparison performed against the linked publication and official release notes; the two numerical analyses and raw inputs are already pinned in the project and private Azure. No author email was sent.
