# Hypothesis ledger | ideas must predict something

This is an active queue, **not** a list of discoveries. Each entry names a mechanism, strongest null and the observation that discriminates them.

**Stable rule:** An interesting correlation is not a particle identification. No hypothesized mechanism earns `BASELINE_REPRODUCED` or a cross-section constraint without real calibrated data and execution receipts.

Every promoted study should link its specific hypothesis ID, source versions, negative controls, limiting cases, measured quantities and a predeclared failure/stopping criterion.
