# Publication readiness | research archive ≠ scientific publication

A paper candidate must pass these gates before a human-approved release:

| Gate | Evidence required |
|---|---|
| **Novelty** | Specific adjacent prior art read at methods/results depth; exact difference stated |
| **Physics validity** | Consistent particle or gravitational model with limiting cases and units |
| **Reproducibility** | Executable code, version pins, input access, hashes, seeds, reproducible results |
| **Statistics** | Likelihood, covariance, selection function, nuisance identifiability, trials and held-out validation |
| **Empirical accuracy** | Source-specific calibration and overlap audit; simulations separated from observations |
| **Interpretation** | Strongest null tested; claims restricted to what the evidence supports |
| **Authorship & ethics** | Accountable human author approves exact release, coauthors consent, target venue policies followed |

**Allowed in this repository:** checked original derivations, executable models, hypothesis logs, failure analyses and clearly labeled exploratory visualizations.

**Not authorized by a GitHub update:** submitting a manuscript to arXiv/journals, representing a new particle discovery, claiming institutional affiliation or posting restricted collaborator material.

A first paper-worthy result may be a rigorous **negative identifiability bound** or reusable likelihood-validation method, provided its novelty and observational relevance survive independent checks.
