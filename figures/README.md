# Figures | show what was measured and what was imagined

Build a visual atlas, but **never decorate evidence into existence**.

**Required labeling for every figure:**

| Label | Meaning |
|---|---|
| **OBSERVED DATA** | Derived from an identified observational release, with its uncertainty model, observing dates, calibration and citation |
| **SIMULATED DATA** | Generated by named equations/software with seed, parameters and units |
| **MODEL FORECAST** | Future or unmeasured predictions under stated assumptions |
| **EXPLANATORY DIAGRAM** | Conceptual schematic, not data |

## Image standards

Prefer **SVG** for mathematical diagrams and vector plots; high-resolution PNG (at least 2000 px wide where appropriate) for rasterized results. Keep underlying CSV/JSON values and producing scripts beside each research result. Captions should identify dataset or generating truth, axes, units, transformations, uncertainty bands and what the figure *does not* establish. Distinguish interpolation curves from independent observations.

Use public external figures only when licenses permit, with creator/license/source attribution. A repository link to an article is often safer than copying a publication's figure. No watermark stripping or invented source credits. If the input data are inaccessible, draw an appropriately labeled schematic rather than implying the graph is empirical.
